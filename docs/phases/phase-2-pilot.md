# Phase 2 · Pilot

Weeks: 3–4

## Deliverables

- Both pilot repos on Otter for daily work.
- CI reviewer agent commenting on every pilot PR.
- Fix gaps in the stack pack as they come up.

## Gate to pass

**C:** rework on AI-assisted PRs at or below baseline.

This is the critical phase: it shows whether the harness reduces rework on our own code. If Gate C fails, fix the stack pack and extend the pilot rather than rolling out.
